# Find Skills

Скилл помогает находить и устанавливать скиллы из открытой экосистемы агентских скиллов.

## Когда использовать

Когда пользователь:

- спрашивает «как мне сделать X», где X — распространённая задача, под которую скилл может уже быть;
- говорит «найди скилл для X» или «есть ли скилл для X»;
- спрашивает «умеешь ли ты X», где X — специализированная возможность;
- выражает желание расширить возможности агента;
- ищет инструменты, шаблоны или готовые процессы;
- упоминает, что ему пригодилась бы помощь в конкретной области — дизайн, тестирование, деплой.

## Что такое Skills CLI

Skills CLI (`npx skills`) — пакетный менеджер открытой экосистемы агентских скиллов. Скилл здесь
модульный пакет, расширяющий возможности агента специализированными знаниями, процессами и
инструментами.

**Основные команды:**

- `npx skills find [query]` — поиск скиллов интерактивно или по ключевому слову
- `npx skills add <package>` — установка скилла с GitHub или из другого источника
- `npx skills check` — проверка обновлений
- `npx skills update` — обновить все установленные скиллы

**Каталог:** https://skills.sh/

## Как искать

### Шаг 1: понять, что нужно

По запросу пользователя определить:

1. Область — React, тестирование, дизайн, деплой.
2. Конкретную задачу — писать тесты, делать анимации, ревьюить PR.
3. Насколько задача распространена, чтобы под неё вообще существовал скилл.

### Шаг 2: сначала посмотреть лидерборд

До запуска поиска через CLI заглянуть в [лидерборд skills.sh](https://skills.sh/) — не покрыт ли
запрос уже известным скиллом. Лидерборд ранжирует по числу установок и поднимает наверх самые
популярные и обкатанные варианты.

Например, для веб-разработки в топе:

- `vercel-labs/agent-skills` — React, Next.js, веб-дизайн (100K+ установок каждый)
- `anthropics/skills` — фронтенд-дизайн, обработка документов (100K+ установок)

### Шаг 3: искать

Лидерборд запрос не покрыл — запустить поиск:

```bash
npx skills find [query]
```

Например:

- «как ускорить моё React-приложение?» → `npx skills find react performance`
- «поможешь с ревью PR?» → `npx skills find pr review`
- «нужно сделать changelog» → `npx skills find changelog`

### Шаг 4: проверить качество до рекомендации

**Не рекомендовать скилл только по выдаче поиска.** Проверять всегда:

1. **Число установок** — предпочитать 1K+, к тому, что ниже 100, относиться настороженно.
2. **Репутация источника** — официальные (`vercel-labs`, `anthropics`, `microsoft`) надёжнее
   неизвестных авторов.
3. **Звёзды на GitHub** — смотреть исходный репозиторий; репозиторий с менее чем сотней звёзд
   заслуживает скепсиса.

### Шаг 5: показать варианты

Найденные скиллы показывать с:

1. именем и тем, что скилл делает;
2. числом установок и источником;
3. командой установки;
4. ссылкой на подробности на skills.sh.

Пример ответа:

```
Нашёл подходящий скилл: "react-best-practices" — рекомендации по производительности
React и Next.js от инженеров Vercel. (185K установок)

Установить:
npx skills add vercel-labs/agent-skills@react-best-practices

Подробнее: https://skills.sh/vercel-labs/agent-skills/react-best-practices
```

### Шаг 6: предложить установку

Если пользователь согласен, установить за него:

```bash
npx skills add <owner/repo@skill> -g -y
```

Флаг `-g` ставит глобально, на уровень пользователя, `-y` пропускает подтверждения.

## Частые категории

| Категория | Примеры запросов |
| --- | --- |
| Веб-разработка | react, nextjs, typescript, css, tailwind |
| Тестирование | testing, jest, playwright, e2e |
| DevOps | deploy, docker, kubernetes, ci-cd |
| Документация | docs, readme, changelog, api-docs |
| Качество кода | review, lint, refactor, best-practices |
| Дизайн | ui, ux, design-system, accessibility |
| Продуктивность | workflow, automation, git |

## Как искать эффективнее

1. **Конкретные ключевые слова:** «react testing» лучше, чем просто «testing».
2. **Пробовать синонимы:** не сработало «deploy» — попробовать «deployment» или «ci-cd».
3. **Смотреть популярные источники:** многое живёт в `vercel-labs/agent-skills` и
   `ComposioHQ/awesome-claude-skills`.

## Если ничего не нашлось

1. Прямо сказать, что подходящего скилла не нашлось.
2. Предложить сделать задачу самому, общими возможностями.
3. Подсказать, что пользователь может завести собственный скилл через `npx skills init`.

Пример:

```
Искал скиллы по «xyz», совпадений нет.
Могу сделать это напрямую — продолжать?

Если задача повторяется, можно завести свой скилл:
npx skills init my-xyz-skill
```
