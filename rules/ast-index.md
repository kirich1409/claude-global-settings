# Поиск по коду

`ast-index` — основной инструмент навигации по символам: быстрее и точнее Grep на задачах «найти класс / использования / реализации / вызывающих». Полный синтаксис — `ast-index --help`.

Grep остаётся правильным выбором для строковых литералов, regex, текста комментариев и значений конфигов. LSP — когда нужно семантическое разрешение типов.

Перед `Read` файла длиннее ~500 строк — `ast-index outline <file>`, затем читать нужный срез через `offset`/`limit`.

Индекс поддерживается хуками: SessionStart делает `update` (или `rebuild`) и поднимает один экземпляр демона `watch` на проект, PostToolUse:EnterWorktree инициализирует свежий worktree, SessionEnd останавливает watcher. Ручной `update` в обычной работе не нужен.

«Index not found» или `⚠ AST INDEX NOT AVAILABLE` в session reminder → `ast-index rebuild` через Bash (работает из любого агента, включая Explore), затем повторить поиск.
